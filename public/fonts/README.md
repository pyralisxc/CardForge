# CardForge Local Fonts

CardForge self-hosts these font files so the editor, previews, and exports do not depend on runtime Google Font requests.

Fonts in this folder are the curated built-in set. Reviewed developer-submitted fonts do not belong here; they publish through the Forge Review asset registry and load through `/api/fonts`.

The built-in files were downloaded from the Google Fonts repository and are used under their open font licenses. Keep direct additions limited to fonts with redistribution-friendly licenses and update this file when adding a built-in family.

Current families:

- Alegreya
- Barlow Condensed
- Cinzel
- Cormorant Garamond
- EB Garamond
- Lato
- Orbitron
- Rajdhani
- Spectral
- Uncial Antiqua
