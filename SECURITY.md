# Security Policy

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability.

Report security concerns privately through the repository owner's GitHub profile contact channel. Include the affected route or feature, reproduction steps, expected impact, and any evidence that can be shared safely. Do not include secrets, customer data, payment data, or destructive proof-of-concept payloads.

CardForge will acknowledge a complete report, assess severity, prepare a fix, and coordinate disclosure when appropriate. No bug-bounty payment is promised.

## Supported version

Only the current production release on `main` is supported.
